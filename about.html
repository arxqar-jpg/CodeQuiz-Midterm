ABOUT THE PROJECT

We turned revision into a small coding game.

CodeQuiz is a responsive mini website for students who want a fast, clear way to check programming fundamentals and track simple progress.

> project.name = "CodeQuiz"

> project.type = "Responsive website"

OUR IDEA

What CodeQuiz does

Users choose a programming topic, answer multiple-choice questions, read short explanations and receive a final score, XP reward and achievement badge.

  • ✓ Fast five-question practice rounds
  • ✓ Clear feedback after every answer
  • ✓ Best scores saved locally in the browser
  • ✓ Responsive layout from mobile to desktop

DESIGN PRINCIPLES

Why the interface looks this way

01

Readable

High contrast, visible focus states and comfortable spacing make the pages easy to scan.

02

Consistent

The same navigation, buttons, cards, border radius and color rules are reused on every page.

03

Responsive

Bootstrap columns and custom media queries adapt the layout for desktop, tablet and mobile.

PROJECT STRUCTURE

One shared design system

All four pages use the same stylesheet and JavaScript file, so the project stays consistent and easy to maintain.
